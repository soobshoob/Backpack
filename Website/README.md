# Backpack Website

Развитие существующего React + TypeScript + Vite сайта, без публикации и изменения приложения. Новая демонстрация: [qa/onboarding/REPORT.md](qa/onboarding/REPORT.md). Интеграции: [qa/stage1/REPORT.md](qa/stage1/REPORT.md). Подключение: [INTEGRATIONS.md](INTEGRATIONS.md), контракт: [REGISTRY.md](REGISTRY.md), передача: [qa/Stage2-GitHub-Handoff.md](qa/Stage2-GitHub-Handoff.md). Старые QA-папки сохраняют историю.

## Запуск

Обычный способ сохранён: двойной щелчок по Start-Website.cmd, либо pnpm dev. Если стандартный порт занят, Vite выберет следующий свободный; используйте адрес из вывода. Во время этой работы просмотр доступен на http://127.0.0.1:5174/.

Сборка: pnpm build. Размещение и корректные вложенные URL описаны в [HOSTING.md](HOSTING.md). Сайт рассчитан на корень домена. HTML создан заранее для одиннадцати страниц, 404 и generic plugin shell. После подключения реестра новые slug получают данные без пересборки; требования fallback — в INTEGRATIONS.md.

## Разделы

- / — hero, единый 32-секундный сценарий знакомства с текущим интерфейсом приложения, асимметричные демонстрации, четыре избранных расширения, компактные профили/приватность, developers, выпуск, FAQ.
- /plugins — поиск по названию/описанию/автору/тегам, категории в URL, отдельное обозначение пустого публичного каталога и шесть примеров автора. Нет вымышленных рейтингов и дат.
- /plugins/:slug — статус, версия, демонстрация, галерея, совместимость по явно выбранной версии, возможности, лицензия и известные/неизвестные метаданные.
- /plugins/publish — помощник валидной записи index.json: публичные package/release/image URLs, метаданные, живое превью, копирование и скачивание JSON для Pull Request. Локальные изображения не загружаются и не попадают в запись. PR/merge автоматически не выполняются.
- /download — два канала Store/stable Releases, отдельный локальный preview, добровольная поддержка в неоновой рамке с фирменными карточками сервисов. Незаданные ссылки не активны.
- /developers — девять разделов с проверенным SDK 1.1, командами сборки реального Timer и фрагментом его кода, импортом, доверием и лицензией.

Рисование и раскладка остаются запланированными самостоятельными плагинами, хотя их прежние инструменты работают в приложении. Ядро целевой модели — клавиши и мышь; профили, оформление, приватность и управление расширениями — инфраструктура. Линза, фокус, увеличение у курсора и таймер — отдельные проверенные комплектные примеры, а не публичные загрузки.

Проверенный пакет: Backpack 0.4.0-preview.4, Windows 10/11 x64, unsigned/unpublished, SDK 1.1. Источники: Phase4G-Implementation-Report, release notes preview.4, SHA256SUMS, docs/plugins/README.md и sample-проекты. Все ссылки пакетов/репозитория остаются null до реальной публикации; профиль автора не подменяет репозиторий.

Существующая лицензия — PolyForm Strict 1.0.0. Backpack не объявлен open source. Обновлённые условия SDK готовятся; сайт не выдаёт дополнительных прав на изменение или распространение производных работ. Файлы лицензий приложения и SDK не менялись.

## Код и данные

- src/App.tsx — общий Header/Footer, языки, пауза и выбор страницы; src/Home.tsx — главная.
- src/router.ts — небольшая History API маршрутизация без новой зависимости, приоритет publish перед slug, запросы каталога в URL и Back/Forward.
- src/product.ts — проверенные факты выпуска и реализованное/проверенное/публичное состояние плагинов.
- src/catalog.ts и public/catalog-index.json — канонические записи и загружаемый локальный индекс; тестовые данные не входят в каталог.
- src/pages — каталог/подробности, локальная форма, руководство.
- src/publication.ts — отдельная валидация полей/версий/HTTPS URL, сигнатур и размеров файлов; экспорт только метаданных. Это не проверка безопасности кода плагина.
- src/components/OnboardingDemo.tsx + src/animation/onboarding.ts — один постановочный проход Home → стили клавиш → Plugins → Focus → искусственная рабочая сцена → Esc → логотип Home. Геометрия сверена с запущенным preview.5, факты выпуска сайта остаются preview.4.
- src/hooks/useOnboarding.ts — отдельные play/pause/restart, общая пауза, viewport/hidden freeze и явный запуск при reduced motion; src/onboardingCopy.ts — подписи и элементы UI на 18 языках.
- src/components/PluginCard.tsx и Gallery.tsx — общий каталог и клавиатурная галерея. public/previews — оптимизированные WebP-кадры синтетических демонстраций сайта, не снимки приложения.
- src/hooks/useDemo.ts — активное время, requestAnimationFrame, viewport/visibility, пауза/reduced motion, очистка ресурсов. Настоящие клавиши, пароль, буфер и экран не считываются.
- src/v102.css — новая композиция поверх прежних Emerald-стилей; крупные заголовки/бренд/клавиши сохраняют Spectral, основной текст и UI используют system sans-serif.
- src/locales — 18 локальных языков без русского; неподдерживаемое сохранённое ru игнорируется. src/siteCopy.ts и siteExtra.ts содержат новые интерфейсные подписи. Руководство полностью написано на en/uk/de; в остальных языках технические абзацы явно отмечены lang=en, навигация и интерфейс локализованы.
- scripts/apply-model-copy.mjs + update-release-copy.mjs — генерация словарей с актуальными фактами Phase 4G. Внешняя служба перевода не используется.

Шрифты и сторонние лицензии сохранены локально; происхождение — THIRD-PARTY-NOTICES.md и REFERENCE-MAPPING.md. Новых библиотек и тяжёлого движка не добавлено.

## Проверки

pnpm test — 54 логических проверки, включая существующую приватность/шрифты/локализацию и новую модель/форму/поиск.
pnpm verify:static — после сборки: все вложенные HTML, ссылки, ресурсы, галереи, шрифты, состояние выпуска и контрастные пары.
pnpm test:browser — функции и 150 сочетаний страниц/размеров/языков/масштаба.
pnpm test:languages — 90 сочетаний всех 18 языков и пяти страниц при тексте 200%.
pnpm test:cycles — три полных 32-секундных прохода, запись WebM, мобильный цикл, управление/пауза/hidden/viewport/reduced motion и регрессия Bento. Приватность также покрыта существующими логическими проверками.
pnpm qa:serve — файловая production-сборка на 5176; затем pnpm test:production.

Браузерные проверки используют установленный Chrome с отдельным временным профилем, не персональный профиль. При другом расположении задайте CHROME_PATH. Dev-тесты по умолчанию используют 5173; для занятого порта задайте BACKPACK_BASE_URL, например http://127.0.0.1:5174. Старые скрипты в tests и QA-папки остаются историческими материалами предыдущих композиций.

Ничего не опубликовано и не закоммичено. Новая модель публикации — публичный GitHub index.json и ручной PR review/merge владельцем, без собственного backend сайта. Единая конфигурация сервисов и подтверждённых лицензий — src/integrations/settings.json; пример без секретов — integrations.example.json. Нужны реальные адреса, публикация репозитория/Releases и решение о лицензии SDK. Никаких GitHub Actions/FUNDING/root LICENSE изменений на первом этапе не выполнено.

Интеграционные проверки: node tests/stage1-browser.mjs при отдельном pnpm dev --mode integration-test --port 5177 --strictPort. Все HTTPS ответы управляемые; этот режим явно помечен и не входит в обычную production-сборку. Для тестирования нескольких режимов кеши Vite разделены, чтобы fixtures не вызывали Outdated Optimize Dep у обычного сервера.
