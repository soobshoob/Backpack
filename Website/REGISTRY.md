# Предлагаемый контракт index.json v1

Это контракт сайта для второго этапа, не существующий внешний сервис. Канонический валидатор — `src/integrations/registry.ts`; структурная JSON Schema — `public/registry.schema.json`, генератор — `scripts/registry-schema.mjs`. В CI требуется проверять и схему, и семантические ограничения валидатора.

Корень: `{ "schemaVersion": 1, "plugins": [] }`. Неизвестная версия схемы отклоняется явно; неизвестные поля не принимаются. Максимум 500 записей и 2 MiB ответа UTF-8. Требуются уникальные ID и slug. Реестр не содержит заявок «на рассмотрении»: запись появляется в публичном index только после ручного одобрения и merge.

| Поле | Обязательность и формат |
|---|---|
| id | Обязательно, до 150 символов, lowercase сегменты через `.`/`-`, например reverse-DNS идентификатор автора. |
| slug | Обязательно, lowercase слова через дефис, до 80; publish/_route зарезервированы. |
| name | Объект переводов с обязательным en, до 100 символов на значение. |
| author | `{name, url?}`, имя до 100; URL публичный HTTPS. |
| summary / description | Объекты переводов с en, до 300/12000 символов. Только обычный текст; HTML не исполняется. |
| version | SemVer, без v-префикса, включая корректные prerelease/build identifiers. |
| category | tools, mouse, keystrokes, focus, drawing, styles, productivity или integrations. |
| tags | Обязательный массив, может быть пустым; максимум 20 строк до 80 символов. |
| distribution | `{kind, url, sha256?, sizeBytes?}`. kind: package или release. |
| compatibility | `{minBackpack, maxBackpack?, sdk, platforms}`. Версии SemVer, max не ниже min; SDK major.minor. |
| license | Обязательно `{name, url?}`. Это собственные условия плагина; не наследуется лицензия ядра или SDK. |
| repositoryUrl | Необязательный публичный HTTPS URL. |
| icon | Необязательный HTTPS PNG/JPEG/WebP. |
| images | До 8 объектов `{url, alt}`; alt — объект переводов с en. Только PNG/JPEG/WebP. |
| updatedAt | Необязательный настоящий ISO date-time; неизвестную дату не выдумывать. |
| capabilities | Необязательный массив до 50 строк; декларация не является гарантией безопасности. |
| changelog | Необязательный объект переводов, до 12000 символов на значение. |

Все публичные URL — до 2048 символов, HTTPS без credentials/нестандартного порта, не localhost/локальная сеть/локальный Windows-путь. Растровый формат проверяется по расширению URL; сайт не запускает содержимое и не выполняет проверку безопасности кода. Метаданные/файлы всё равно требуют проверки владельцем.

`package` указывает прямо на .bppkg. Допускается SHA-256 из 64 hex-символов именно этого файла; он не подтверждает безопасность. `release` указывает на страницу выпуска, а не бинарный .bppkg/ZIP/EXE/MSI, и не принимает SHA-256 вместо хеша конкретного файла. Размер необязателен и должен быть достоверным.

platforms v1 содержит windows-x64 и, при действительной поддержке соответствующего пакета, windows-arm64. Текущий проверенный Backpack preview.4 — Windows x64; наличие значения ARM64 в контракте не объявляет текущую программу ARM64-совместимой. Страница сравнивает только явно выбранную известную пользователю версию; автоматического обнаружения установленного Backpack нет.

Ключи переводов — языковые коды; en — fallback, не требуется дублировать все языки сайта. Помощник /plugins/publish создаёт en-поля; дополнительные переводы можно добавить в JSON перед PR.

Помощник готовит **одну запись**, не переписывает существующий index. Нужно добавить её в массив plugins существующего index, не удаляя чужие записи, выполнить проверки и открыть PR. Генерация/копирование/скачивание JSON не создаёт PR, не подтверждает его приём и не публикует плагин. Публичные URL пакетов/картинок автор предоставляет заранее. Локальные preview files/object URLs не попадают в запись.

Подробные страницы читают тот же реестр, что каталог. Новые slug требуют file-first + generic plugin-route fallback на хостинге (см. INTEGRATIONS.md/HOSTING.md), затем появляются без редактирования React-компонентов. TTL по умолчанию 5 минут, ручная проверка доступна; старый корректный кеш до 7 дней явно подписан. При ошибке нового JSON кеш не считается свежим подтверждением.
