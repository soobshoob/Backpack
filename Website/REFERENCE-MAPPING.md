## Осознанные отличия от постера

- Фиктивные версия, бесплатность без ограничений, open-source, готовые обновления, GitHub проекта и социальные сети удалены.
- Показан последний документально проверенный выпуск 0.3.0-preview.2.
- Нет активной загрузки, пока пакет не опубликован. Есть реальные локальные release notes и полный SHA-256.
- Интерфейс создан компонентом `Interface.tsx` и явно обозначен предварительным. Его можно заменить на чистый снимок, не переделывая остальную страницу.
- Затемнение обозначено разработкой; нумерованная отметка — концепцией; динамическая приватность — разработкой с предупреждением о необходимости ручного скрытия в текущем preview.
- Логотип — контурный Backpack из Lucide; favicon — собственный SVG. Растровый постер не вырезался и не использовался как сайт.
- Шрифт Inter выбран явно и размещён локально с OFL. Это не утверждение об определении шрифта референса.

## Анимации

Цикл демонстраций — 6 секунд. Нажатия Ctrl, Shift, S начинаются через 200 мс друг за другом. Сначала показывается левый клик мыши, затем правый, затем прокрутка. Линия рисуется за 1,2 секунды; отметка появляется позже. В демонстрации приватности кейкапы исчезают до защищённого состояния, реального поля пароля нет.

Движение прекращается вне экрана, при скрытой вкладке и общей паузе. При reduced motion — статичные состояния, без автоматических переходов и параллакса. Сайт не слушает реальную клавиатуру и не захватывает экран.

## Product model revision — 2026-10-30
Final owner refinements: actual running-app title bar/sidebar/settings grouping restored after native inspection; emerald highlighted cursor clicks precede page changes. The interface is capped at 900 px. Two core cards retain half-row widths with reduced heights; six portrait plugin cards form a horizontal rail with faded edges and full-surface scenes. Current captures are qa/product-model/compact-*.png.
The source composition, palette, emerald accents, logo, materials, rounded borders, large-heading sizing and keycap renderers are retained. Body text/controls now use system UI sans-serif; display headings and the brand keep Spectral and the local Greek fallback. Keys and mouse occupy the core block. Six independently classified author-plugin cards replace the mixed built-in tools grid. Profiles/input privacy are application infrastructure. New workflow, timer and layout scenes use the existing active-time animation lifecycle. See qa/product-model/REPORT.md and before/after captures.
