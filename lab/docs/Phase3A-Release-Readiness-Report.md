# KeyOverlay — Phase 3A: готовность к выпуску и канал обновлений

**Дата:** 2026-10-29
**Пакет-кандидат:** `artifacts/release/KeyOverlay-0.3.0-preview.1-win-x64.zip` (≈ 73 МБ), канал Preview, дата выпуска в метаданных 2026-10-29 (задана параметром скрипта), **не подписан, не опубликован**.

---

## 1. Реализовано

### 1.1 Обычный запуск отдельно от стенда

- Один исполняемый файл `KeyOverlay.exe` (прежде `KeyOverlay.Lab.exe`); реализация захвата одна.
- Без `--lab`: главное окно «Главная» (или только трей с `--minimized`), окно диагностики при запуске не открывается. Допустимы только `--settings` и `--minimized`; параметры стенда без `--lab` отклоняются с сообщением.
- С `--lab`: прежнее окно диагностики и все инструменты (`--source`, `--ring`, `--selftest-ui`, `--render-*`, `--summary-out`, `--auto-exit-ms`).

### 1.2 Сборка и упаковка

- Метаданные версии — `lab/Directory.Build.props`: `0.3.0-preview.1`, канал, дата выпуска (пусто в сборке разработчика), репозиторий обновлений (пусто), лицензия (пусто); детерминированная сборка, без хеша коммита в версии.
- `tools/package-release.ps1 -ReleaseDate ГГГГ-ММ-ДД [-UpdateRepository владелец/репозиторий] [-Channel Preview|Stable] [-SkipTests]`:
  тесты в Release → `dotnet publish -c Release -r win-x64 --self-contained` (папка, не single-file) → удаление .pdb и временных файлов → `Licenses\` (Inter OFL, .NET LICENSE и ThirdPartyNotices) → `README.txt` (запуск, portable, обновление, удаление, приватность, предупреждение о неподписанном файле), `RELEASE-NOTES.md`, `THIRD-PARTY-NOTICES.md`, `LICENSE-STATUS.md` → защита от включения `references\`, `research\`, снимков экрана → контрольные суммы всех файлов (`*.files.sha256`) и архива (`SHA256SUMS.txt`). Stable с предварительной версией не собирается. Дата выпуска — только явным параметром.
- Воспроизводимость: сборка детерминированная (`Deterministic`, `ContinuousIntegrationBuild`); архив `Compress-Archive` не побайтно воспроизводим (метки времени файлов в zip) — сравнивайте `*.files.sha256`.

### 1.3 Данные и миграция

- `%APPDATA%\KeyOverlay`; portable — файл `KeyOverlay.portable` рядом с exe и доступная для записи `Data` (иначе `%APPDATA%` и сообщение). Запись в папку программы не требуется.
- Перенос из `%APPDATA%\KeyOverlay.Lab`: settings.json, app.json, profiles — копируются, если в новой папке ещё нет настроек; ничего не перезаписывается и не удаляется.
- Форматы: настройки 1/2 → 3, профиль 1 → 2, `app.json` 1 → 2 (с копиями `settings.vN.bak.json` перед первой записью).

### 1.4 Канал обновлений

`Visual/Updates/UpdateChecker.cs`, страница «О программе»:

- GitHub Releases `https://api.github.com/repos/{владелец}/{репозиторий}/releases?per_page=30`, только GET с `User-Agent: KeyOverlay/версия`; настройки, профили и ввод не передаются (тест проверяет запрос).
- Каналы: Stable отбрасывает `prerelease` и версии с суффиксом; Preview принимает оба. Сравнение — SemVer 2.0.
- Показ: номер, дата, описание (до 4000 символов) и кнопка «Открыть страницу загрузки» — только ссылка на `github.com/{владелец}/{репозиторий}/releases…` того же репозитория, после подтверждения.
- Подходящий пакет — вложение с `win-x64` и `.zip`; иначе «версия есть, пакета нет».
- Ошибки: не настроено, нет сети, таймаут 10 с, лимит API (403 + `X-RateLimit-Remaining: 0` или 429), неправильный ответ, прочая ошибка HTTP.
- Периодическая проверка — отдельная настройка «Проверять автоматически», по умолчанию выключена, раз в сутки, уведомление у значка трея.
- Нет скачивания, нет запуска, нет автоматической установки. **Репозиторий не задан** → «Источник выпусков не настроен»; адрес не придуман (профиль автора https://github.com/soobshoob — не репозиторий выпусков).

### 1.5 О программе и лицензии

## 2. Установленные причины ошибок

- Скрипт проверки пакета падал на подсчёте результатов (`.Count` у одиночной строки при `StrictMode`) — исправлено (`@(...)`).
- Комментарий с `--` в `.csproj` ломал загрузку проекта — исправлен.

## 3. Гипотезы

- SmartScreen/антивирус могут предупреждать о неподписанном `KeyOverlay.exe` — не проверялось на «чистой» системе; в README пакета это сказано, отсутствие предупреждений не обещается.
- Размер пакета (~73 МБ) в основном runtime .NET + WPF; можно уменьшить (обрезка недоступна для WPF), не исследовалось.

## 5. Подготовленные, но не выполненные ручные проверки

1. Распаковать zip на другом компьютере без .NET, запустить двойным щелчком → предупреждение SmartScreen (если будет) → главное окно.
2. Перенос настроек: на компьютере с прежним стендом первый запуск → сообщение о переносе в диагностике, профили на месте; `%APPDATA%\KeyOverlay.Lab` не тронут.
3. Portable: создать `KeyOverlay.portable` → настройки в `Data`; папка только для чтения (например, Program Files) → `%APPDATA%` и сообщение.
4. Обновление: заменить папку программы новой → настройки сохранились.
5. Удаление: выйти, удалить папку и `%APPDATA%\KeyOverlay` → в реестре ничего, автозапуска нет.
6. Канал обновлений после выбора репозитория: собрать с `-UpdateRepository`, выпустить тестовый Preview-релиз → «Доступна версия…», кнопка ведёт на страницу выпуска; Stable — предварительный выпуск не предлагается.
