# Phase 4I — отчёт о выполнении (0.4.0-preview.5 → 0.4.0-preview.6)

Дата: 31.10.2026. Работа локальная: репозиторий не создавался, коммитов, push, публикаций и релизов нет, сертификат не
покупался, пакет **не подписан**. Сайт (`Website/`) только читался. Старые архивы и их суммы не менялись (проверено:
`sha256sum -c` по снимку до упаковки — все 19 файлов совпали; в `SHA256SUMS.txt` добавлена только строка preview.6).
Ваш запущенный Backpack preview.5 не трогался.

## Причины и исправления по пунктам

| № | Что | Причина / решение |
|---|---|---|
| 1 | Шапка страниц | Шапка была адаптивной строкой, центрировала элементы по всей высоте строки — крупное или перенесённое название сдвигало стрелку и сброс. Новый `Settings/PageHeader.cs`: [назад · название · действия], центр по первой строке названия, сброс у правого края (отступ как у карточек), ниже кнопок окна. Общий для всех страниц, включая плагины. |
| 2 | Значки плагинов | `manifest.json → "symbol"` (имя встроенного значка Lucide, без XAML и сетевых ресурсов; проверка формата), переопределение пользователем по ID в `plugins.json` (переживает обновления), выбор с поиском на странице плагина «Отображение». Шесть плагинов от создателя: pen-tool, globe, zoom-in, scan-search, focus, timer. Звезда — только «В меню». |
| 3 | Вторая подпись прыгала после отпускания | Подписи пересоздаются при смене состояния, а `ArrangeOverride` кейкапа WPF не вызывает, если размер не изменился → новая подпись в (0,0). Слой подписей сам ставит её до раскладки. Регрессия: все рендеры × углы × анимация, нажата → отпущена → гаснет → снова нажата. |
| 4 | Клавиши перестают отображаться | **Не воспроизведено, не объявлено исправленным.** Найдено и исправлено: лимит восстановления окна оверлея (5 раз за всю жизнь процесса → потом окно не восстанавливалось никогда, помогал только «скрыть/показать») → 5 раз за 5 минут; проверялось только первое окно оверлея → все; запись в stdin плагинов на UI-потоке → очередь в отдельном потоке. Диагностика `--display-trace=файл` и раздел Display в экспорте: счётчики и этап остановки, без текста. Прогон в своём окне: 20,7 мин (из 60 — завершился при выходе из трея), 565/565 тестовых нажатий показаны, 0 утечек из поля пароля, память ~240 МБ стабильно. |
| 5 | Дуги и углы | Дуга по трём точкам (коллинеарные → отрезок), три ручки; угол из двух прямых, градусы (меньший угол) во время удержания, подпись не под указателем и в пределах экрана, кнопка «оставлять подписи». |
| 6 | Shift/Alt | Квадрат/круг, шаг 15° для линий и поворота многоугольника, от центра; работает во время жеста; короткая подсказка один раз на инструмент. |
| 7 | Выделение | Ручки размера и поворота, курсоры, Shift — пропорции/шаг 15°, Alt — от центра, Esc — отмена, одна запись истории на жест; толщина линии постоянна, текст масштабируется целиком, номера только перемещаются. |
