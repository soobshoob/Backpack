# Phase 4E — единая система оформления, навигация, приватность, рисование, шрифты

Выпуск: `artifacts/release/Backpack-0.4.0-preview.2-win-x64.zip` (87,4 МБ), SHA-256 `73459a618355fafe7fb63d5a9ccf20be45d644795b4f56da719d3f619d28c47a`, дата выпуска 2026-10-30. Пакет не подписан и не опубликован. Пакет 0.4.0-preview.1 и его папка не изменялись; `SHA256SUMS.txt` содержит строки всех четырёх выпусков.

## Порядок работы

Сначала составлена карта проблем: ошибочный запуск лупы по сочетанию «Фокус», пять отдельных сочетаний вне каталога команд, потеря Tab/Win в приватности, призрачные системные кнопки заголовка, глифы Unicode на панели рисования, иллюстрации только для одной темы. Затем шла реализация по пунктам. Каждое исправление сопровождается регрессионным тестом.

## Результаты проверок

- Тесты Release: Core **84/84**, Visual **329/329** (18 новых `Phase4ETests`, 8 новых `PrivacyGateTests`, обновлённые тесты навигации, справки, форматов и миграций). Тесты прошли и при сборке пакета.
- Картинки справки перерисованы: 142 файла, каждая используется, тёмные варианты подставляются в тёмной теме.
- `verify-package.ps1` для распакованного пакета: **26 PASS, 0 FAIL** (SHA-256, путь с пробелами, состав, лицензия, без .pdb, self-contained, без прав администратора, лабораторный запуск, самопроверка окон, хост плагина, обычный запуск, процессов не осталось).
- Исправлена ошибка `verify-package.ps1`: ожидаемая сумма бралась из первой строки `SHA256SUMS.txt` (выпуск 0.3.0), теперь — из строки проверяемого zip.
- Самопроверка `--selftest-ui`: первый прогон этой фазы — 353/355 (ошибка регистра идентификатора категории радиального меню, исправлена). Второй прогон не прошёл шаги приватности: на переднем плане было окно пользователя, а синтетический ввод отправляется только в собственное тестовое окно. **Повторный полный прогон после исправлений не выполнен**: всё это время за компьютером работал пользователь.

## Не проверено

1. Полный повторный прогон `--selftest-ui` (шаги 12 и приватность с синтетическим вводом Tab/Q/W/E в собственном окне). Нужен компьютер без активной работы пользователя.
2. Масштабы 100, 125, 175 и 200 %: у машины один монитор 2560×1600 при 150 %. Масштаб Windows не менялся, чтобы не нарушить работу пользователя. Расчёты DIP для других масштабов покрыты тестами, но это не проверка на экране.
3. Второй физический монитор не подключён; размещение радиального меню и окон по мониторам проверено только тестами.
4. Рисование настоящей мышью рукой и Win-сочетания в настоящих полях сторонних приложений (Win+E, Win+R). Проверены тестами и синтетическими событиями.
5. Клавиатурный обход всех страниц экранным диктором. Имена автоматизации заданы, Tab-порядок проверен тестами, но живой проход не выполнялся.
6. Mica, Acrylic и Liquid Glass на живом экране в обеих темах, а также ручная проверка поведения заголовка (перетаскивание, двойной щелчок, системное меню, Snap Layouts). Картинки справки сделаны в непрозрачном материале, потому что подложка DWM в растр не попадает.

## Прочее

- Экземпляр пользователя (PID 40724) не трогался. Останавливались только процессы, запущенные мной с отдельными настройками (по PID из своих файлов). В ходе работы этот экземпляр оказался закрыт; моей команды на это не было.

- Ничего не коммитилось и не публиковалось, лицензии не менялись, сайт не изменялся.
