# Phase 4D — плагины, SDK, справка, portable-пакет

## Архитектурное решение (зафиксировано до реализации)

`docs/plugins/ADR-0001-plugin-trust.md`: каждый внешний плагин — **отдельный процесс** (`Backpack.exe --plugin-host <папка>`) в Job Object (завершается вместе с Backpack, без дочерних процессов), загрузка в `AssemblyLoadContext` (не песочница), обмен — ограниченный IPC (строки JSON через stdin/stdout, ≤ 64 КБ, ≤ 60 сообщений/с). **Только доверенные плагины**: явное подтверждение перед первым включением; защиты от вредоносного native-кода нет и не обещается. Возможности manifest проверяются на границе на каждое сообщение. Интерфейс плагина (настройки, панель) рисует хост.

## Установленные причины

- `SHA256SUMS.txt` перезаписывался скриптом упаковки целиком (строка прошлого выпуска пропадала). Строка preview.2 восстановлена (хеш файла совпал с отчётом 3B: `3e62dbca…f398267`), скрипт теперь обновляет только строку своей версии и пишет отдельный `.sha256`. Сами пакеты 0.3.0 не изменялись.
- Числа, записанные как `int` в `JsonObject`, не читались через `TryGetValue<double>` — настройки плагина сбрасывались на значение по умолчанию (найдено тестом).
- Ключ `warnSeconds` отвергался шаблоном ID (найдено самопроверкой плагина).

## Не выполнено вручную

1. Импорт `.bppkg` через диалог файла и подтверждение доверия мышью; пользовательские сочетания для команд плагина.
2. Плагин, который зависает в `OnCommand` или потребляет память; поведение Job Object на системах с политиками безопасности.
3. Стороннее антивирусное ПО на запуск `Backpack.exe --plugin-host`.

## Ограничения и решения владельца

- **Модель доверия**: плагины не изолированы ОС; процесс плагина имеет права пользователя. Возможности ограничивают только то, что передаёт и принимает Backpack.
- Встроенные инструменты не переведены на общий контракт компонентов плагинов (не было безопасного способа без большого переписывания); «Фокус» и увеличение у курсора используют общий движок `MagnifierSurface` с раздельными настройками и жизненным циклом.
- Лицензия SDK и примера не менялась: они под PolyForm Strict 1.0.0 вместе с репозиторием, что не разрешает третьим лицам создавать производные работы — решение владельца (`docs/release/LICENSE-STATUS.md`, п. 5).
- Пакет не подписан; адрес обновлений не задан; репозиторий и GitHub Release не публиковались; коммиты не создавались.
