# Проверка аппаратной Fn — короткий сценарий (около минуты)

Fn на ноутбуках обычно обрабатывает прошивка клавиатуры: Windows не получает саму Fn, а получает результат сочетания
(другую клавишу, мультимедийную клавишу или ничего). Имитировать это обычной отправкой F-клавиш нельзя, поэтому нужно одно
физическое нажатие на вашем ноутбуке.

Журнал пишет **только служебные клавиши** (F1–F24, мультимедиа, Home/End/PgUp/PgDn, стрелки, модификаторы, неизвестные
коды). Буквы, цифры, знаки, пробел и Enter не записываются никогда; пока закрыта приватность — не записывается ничего.
Запись сама прекращается через 45 секунд или после Esc.

1. Распакуйте пакет `Backpack-0.4.0-preview.5-win-x64.zip` и в его папке выполните (отдельная папка настроек, ваш
   обычный Backpack можно не закрывать):

   ```powershell
   .\Backpack.exe --lab --no-plugins --settings="$env:TEMP\bp-fn\settings.json" --fn-trace="$env:USERPROFILE\Desktop\backpack-fn.txt"
   ```

2. Нажмите и отпустите **Fn** отдельно — 2 раза.
3. По одному разу: **Fn+F1**, **Fn+F5**, **Fn+F6** (или клавиши громкости/яркости вашего ноутбука), **Fn+←**, **Fn+→**,
   **Fn+↑**, **Fn+↓**.
4. Нажмите **Esc** — запись закончится. Закройте окно стенда.
5. Пришлите файл `backpack-fn.txt` с рабочего стола (в нём только строки вида `время  источник  Down/Up  VK  подпись  slot
   флаги`).

Что покажет журнал: если на Fn нет строк — Fn до Windows не доходит (ожидаемо, Backpack её показать не может); если
Fn+клавиша даёт, например, `0xAD VolumeMute` или `0x24 Home` с флагом `Extended` — Backpack показывает именно эту клавишу,
и по журналу можно решить, нужна ли отдельная подпись.
