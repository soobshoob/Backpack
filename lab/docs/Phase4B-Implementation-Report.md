# Phase 4B — Backpack, дизайн-система, навигация и команды

## Реализовано

| Область | Что сделано |
|---|---|
| Имя и пакет | Пользовательское название — **Backpack**: `Backpack.exe`, `Product`, окна, меню, трей, справка (uk/en/ru), About, README пакета, имена снимков `Backpack_…png`, папка снимков «Изображения\Backpack». Внутренние проекты и namespaces `Backpack.*` не переименованы. Версия 0.4.0-preview.1. |
| Логотип | `LogoArt.cs` перерисован: белый контур рюкзака (ручка, корпус, клапан, карман с пряжкой) на тёмно-изумрудном градиенте `#0B5A43 → #063A2B`; одна спецификация для WPF и SVG; упрощённая версия для 16–24 px. Исходники `docs/brand/backpack-logo.svg`, `backpack-logo-small.svg`, PNG 512, лист размеров; `Assets/Backpack.ico` (16–256), `BackpackTray.ico`. |
| Миграция данных | `DataLocations.MigrateFolder`: Backpack (затем Backpack Lab) → `%APPDATA%\Backpack` через временную папку `Backpack.migrating` и одно переименование; исходная папка не меняется (резервная копия); незавершённая попытка повторяется с нуля; повторный запуск не переносит заново и не перезаписывает новые данные; `migrated-from.txt`. Прежний маркер `Backpack.portable` распознаётся. |
| Темы | `UiPalettes`: **Backpack Emerald** (точные HEX владельца: фон `#111513`, карточки `#222825`, акцент `#087F5B`, свечение `#31C99A`, текст `#F2F5F3`), **Классическая** (прежнее оформление Backpack — путь возврата), Сапфир, Янтарь; каждая — светлая и тёмная. Производные токены: hover `#066B4D`, pressed `#055A40` (темнее, чтобы белый текст сохранял контраст), выбранный пункт — тёмная изумрудная подложка + тонкая зелёная граница, заполнение слайдера, свечение, focus, disabled, error. Светлая/тёмная/системная — отдельная настройка. Emerald — по умолчанию для новых установок; при чтении app.json v1–v2 — Emerald с сообщением «вернуть прежний вид: …Классическая». Рамка «Фокуса» не зависит от темы. |
| Типографика | Встроенный Inter (Regular/SemiBold/Bold; шрифт концепта по картинке не определён — не утверждается обратное, Apple-шрифты не добавлялись). Заголовок страницы 30, секция 19, текст 15–15.5, подсказки 13.5 DIP; карточки — скругление 16; навигация — скругление 10. |
| Иконки | Lucide **1.59.0** (`lucide-static`, опубликован 2026-10-17), 66 иконок, геометрия сгенерирована `tools/gen-lucide.py` в `Icons/LucideIcons.g.cs`; лицензии ISC + MIT (Feather) в THIRD-PARTY-NOTICES и `Licenses/Lucide-LICENSE.txt`. Отсутствующие в версии имена → официальные: `layers-3`→`layers`, `circle-help`→`circle-question-mark`, `trash-2`→`trash`. Плагины — `puzzle`, избранное — `star`. |
| Навигация | Плоское меню с иконками: Главная, Клавиши, Мышь, Раскладка, Фокус, Рисование, избранные плагины, Плагины, Профили, Настройки приложения, Справка, О программе. «Стиль кейкапов», «Положение и мониторы» (из «Клавиш») и «Команды и сочетания» (из «Настроек приложения») — подстраницы без собственных пунктов, подсвечивается родитель. «Увеличение у курсора» — внутри «Мыши». Диагностика — только на «Справке». Нижние «Справка (F1)» и «Свернуть в трей» — компактные вторичные действия с иконками. Оглавление справки — строки-ссылки вместо ряда кнопок Open. |
| Инструмент включён | В начале «Клавиш», «Фокуса», «Рисования» — переключатель (app.json `tools`); у «Мыши» и «Раскладки» роль играет их прежний первый переключатель. Выключение закрывает окна, завершает режим, снимает сочетания (команды становятся недоступны и не регистрируются), настройки сохраняются; источник ввода продолжает работу. |
| Команды | `CommandRegistry`: ID, название, категория, область (глобальная / в окнах / только в инструменте), вид (действие, переключатель, выбор, открытие настройки), доступность, отметка. Кнопки, меню трея и сочетания вызывают одну реализацию. Покрыто: открыть Backpack (прежние «Открыть» и «Показать окна» объединены), показ/скрытие, только сочетания, мышь в ряду, значок и круг у курсора, индикатор раскладки, следующий профиль (с тем же вопросом о несохранённых изменениях), справка (F1 — локально), выход; Фокус (линза, затемнение, редактирование), рисование (вкл., отмена, повтор, очистка, умный карандаш, отметки, сброс нумерации), увеличение у курсора (вкл., удержание, на месте), открытие страниц настроек, команды плагинов. `HotkeyManager.ApplyCommands`: общая проверка конфликтов с прежними действиями, MOD_NOREPEAT, «только в инструменте» регистрируются на время режима (рисование, Фокус, увеличение), обычные буквы не становятся глобальными, F2–F24 — только для области инструмента. Новых глобальных сочетаний по умолчанию нет. Страница «Команды и сочетания» со статусами и записью сочетаний. |
| Главная | Текст о наборе инструментов; демонстрация на почти чёрной основе с изумрудным свечением: кейкапы и мышь, стрелка и нумерованная отметка, штрих, превращаемый настоящим распознавателем в эллипс, «Затемнение», «Линза» и круг увеличения у курсора. Пауза, «меньше движения» (app.json `reducedMotion`) и выключенные анимации Windows, остановка при уходе со страницы, без звука. Карточки с Lucide-иконками, действием и переходом к настройкам; технические пояснения («нарисовано тем же кодом») убраны. |

## Результаты проверок

- Visual: `Phase4BTests` (5: перенос с сохранением исходника и без повторного переноса, повтор прерванного переноса, папка Backpack Lab и прежний portable-маркер, плоское меню без дублей с иконками и без «диагностики», все фазы демонстрации и остановка), обновлённые тесты навигации и справки, контраст всех тем (`Phase4ATests`): текст на фоне и карточках ≥ 7:1, белый на акценте/hover/pressed ≥ 4.5:1 (на `#087F5B` — 5.0:1), фокусная рамка ≥ 3:1.
- `Phase4CTests.Command_*` — реестр, доступность, отсутствие сочетаний по умолчанию, области, конфликты, освобождение регистрации, MOD_NOREPEAT.
- Самопроверка окон: все разделы × 3 языка × 2 темы, повторное открытие окна, меню трея из реестра (переключение фильтра и показа), справка.
- Просмотрены рендеры: «Главная» (en/uk), «Настройки приложения» (тёмная Emerald), иллюстрации справки перерендерены (`docs/help/images`).

## Изменения тестов (осознанные)

- Порог контраста «текст на акцентной кнопке» снижен с 7:1 до WCAG AA 4.5:1: прежний порог рассчитывался на чёрно-белый акцент; изумрудный акцент с белым текстом даёт 5.0:1.
- Тесты навигации переведены на плоское меню (вместо раскрывающейся группы «Настройки»); неподдерживаемая версия формата в тестах — 6 (settings) и 4 (app.json).

## Не выполнено вручную

1. Масштаб 125/175/200 % (проверено только 150 % этой машины), очень маленькое окно, увеличение текста Windows.
2. Длинные переводы на всех страницах в узком окне (рендеры проверены выборочно).
3. Миграция настоящих данных Backpack пользователя (проверено на синтетических папках).
4. Иконка в трее и на панели задач при светлой и тёмной теме Windows.

## Ограничения

- Прозрачность: карточки сплошные (без акрилового размытия) — читаемо при любом фоне; «умеренная прозрачность» использована в оверлейных панелях и значке приватности.
- Глифы панели рисования (✎ ╱ ➚ ▭ ◯ T ✦ ①) — символы Unicode, не переведены на Lucide (это предметная графика инструментов, но не все из них «специальные символы клавиш»).
- Иллюстрации справки для новых страниц («Фокус», «Плагины», «Команды») не созданы — тексты разделов есть.
- Название в меню «Раскладка» для en осталось «Keyboard layout».
