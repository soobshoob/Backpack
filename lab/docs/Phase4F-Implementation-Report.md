## Результаты проверок

- Тесты Debug: Core **96/96**, Visual **349/349**. Тесты Release при сборке пакета: Core **96/96**, Visual **350/350**.
- Самопроверка `--selftest-ui` (отладочная сборка, после последних изменений): первый прогон 353 из 364 — все 11 сбоев в старых шагах, ожидавших отдельную страницу «Справка» (её больше нет); шаги исправлены, последующие прогоны — из пакета.
- Распакованный пакет: `verify-package.ps1` — **27 PASS, 0 FAIL** (повторено после пересборки пакета); самопроверка из распакованного пакета — **ok, 354 шага** (дважды: первая и окончательная сборка пакета), в т. ч. 192 раскладки без нарушений, приватность с синтетическим вводом в собственном окне, ручки «Фокуса»; после выхода процессов Backpack не осталось. Сценарий приватности на рабочем столе повторён на распакованном пакете (`privacy-desktop-trace-package.log`): рабочий стол (фокус `SysListView32`) — `Allowed`, Ctrl, Ctrl+A, Ctrl+C, Ctrl+Shift показаны (до 4 кейкапов); поле пароля (`PasswordBox`) — `Protected`, Q/W/E и Ctrl+W скрыты; обычное поле — X/Y/Z показаны.
- В отладочном прогоне самопроверки сочетания `display.toggle`, `tool.focus`, `tool.drawing`, `tool.radial` были «заняты» запущенным тогда экземпляром пользователя; в прогонах из пакета они зарегистрированы.
- Сбой в скрипте проверки (не в приложении): в одном прогоне щелчок по полю пароля пришёлся на окно, ещё восстанавливавшееся после Win+D, фокус остался в обычном поле, и Q/W/E честно были показаны как ввод обычного поля. Прогон повторён с записью элемента в фокусе в каждой метке журнала — результат выше.
- Во время работы по замечаниям пользователя изменены: превью — фиксированная ширина и полная высота, закреплено и в вертикальной компоновке; верхний край прокрутки без линии; ровный столбец значков и квадратное выделение в компактном меню; Spectral только в крупных заголовках и названии программы.

- Масштабы кроме 150 % и 125 % (на этом оборудовании их два; масштаб Windows не менялся).
- Экранный диктор вслух не прогонялся (имена автоматизации заданы, по ним проходили все проверки UIA в этой работе).
- Mica/Acrylic/Liquid Glass вживую не сравнивались (изменений в этой фазе нет).
- Видео сценария рабочего стола не записывалось (личный рабочий стол).
