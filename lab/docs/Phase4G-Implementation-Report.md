## Результаты проверок

- `dotnet test` (Release, в составе упаковки): Core 106/106, Visual 383/383.
- `tools/verify-package.ps1 -SelfTestUi` на финальном zip: 38 PASS, 0 FAIL; `--selftest-ui` из распакованного пакета — `ok, steps 385`,
  четыре плагина из `Plugins\` прошли полный путь.
- Отладочная самопроверка в этой сессии: один прогон дал 4 провала приватности (UIA вернул `NotPassword` для поля пароля);
  в предыдущем и последующих прогонах (в том числе из пакета) они прошли — зависимость от активного окна, код приватности не менялся.
- Пример `Samples\Focus` собирается из распакованного пакета (`dotnet build`, 0 предупреждений), SDK в вывод не копируется.
- Справка: страницы 02, 12, 14, 15, 17 на трёх языках; снимки перегенерированы `--render-help-images` (добавлены страницы
  плагинов — пакеты только импортированы, код не запускался), снимки удалённых страниц Lens/CursorZoom удалены.

## Не проверено и что нужно от пользователя

- **Fn (пункт 8).** Запустите `Backpack.exe --lab --input-trace="%USERPROFILE%\Desktop\fn-trace.txt" --source=compare`, нажмите
  по одному разу Fn+F1, затем Fn+F6 (с паузой ~2 с), дождитесь окончания (2 минуты) и пришлите файл. Журнал покажет, приходит
  ли сам Fn и какие события Raw Input / низкоуровневого хука дают эти сочетания.
- Второй монитор 125 % и перенос инструментов между мониторами.
- Живое наведение на линзу, фокус и таймер с записью; клики сквозь оверлей.
- Плагины на «Главной» не имеют отдельных кнопок запуска (переход на страницу плагинов).
