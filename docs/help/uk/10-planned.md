# Що заплановано

На цій сторінці — те, чого в програмі **ще немає**. Інші розділи довідки описують лише те, що працює.

| Можливість |
|---|
| Виділення модифікаторів кольором |
| Історія: кілька груп натискань на екрані; порядок «як натиснуто» |
| Власний список клавіш у фільтрі; прокручування й перетягування як кейкапи в ряду |
| Вибір монітора для оверлея |
| Імпорт тем Keyviz |
| Автоматичне встановлення оновлень (з перевіркою автентичності й безпечною заміною) |
| Пакет із цифровим підписом |

Автозапуск разом із Windows без окремого рішення не планується.
