# Что запланировано

На этой странице — то, чего в программе **ещё нет**. Остальные разделы справки описывают только работающее.

| Возможность |
|---|
| Выделение модификаторов цветом |
| История: несколько групп нажатий на экране; порядок «как нажато» |
| Свой список клавиш в фильтре; прокрутка и перетаскивание как кейкапы в ряду |
| Выбор монитора для оверлея |
| Импорт тем Keyviz |
| Автоматическая установка обновлений (с проверкой подлинности и безопасной заменой) |
| Пакет с цифровой подписью |

Автозапуск вместе с Windows не планируется без отдельного решения.
