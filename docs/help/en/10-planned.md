# What is planned

This page lists what the program **does not have yet**. All other help topics describe only what works.

| Feature |
|---|
| Color highlighting of modifiers |
| History: several groups of presses on screen; “as pressed” order |
| Own key list in the filter; scrolling and dragging as keycaps in the row |
| Choosing the monitor for the overlay |
| Importing Keyviz themes |
| Installing updates automatically (with authenticity checks and safe replacement) |
| A digitally signed package |

Starting with Windows is not planned without a separate decision.
