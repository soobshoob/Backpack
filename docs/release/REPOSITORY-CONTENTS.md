# What goes into the public repository

Prepared 31.10.2026 for the first push. Nothing was deleted: excluded files are only listed in `.gitignore`.
Check `git status --short --ignored` before the first commit.

## Published

| Path | Contents |
|---|---|
| `README.md`, `LICENSE`, `LICENSING.md`, `NOTICE`, `CONTRIBUTING.md`, `SECURITY.md`, `.gitignore` | project documents |
| `.github/` | workflows `ci.yml`, `release.yml`, `registry.yml`; pull request templates; `FUNDING.yml.example` (inactive) |
| `lab/src/`, `lab/tests/`, `lab/KeyOverlay.Lab.slnx`, `lab/Directory.Build.props`, `lab/README.md` | the core and its tests (MPL 2.0) |
| `lab/sdk/`, `lab/samples/` | SDK and the six plugins from the creator, with their own `LICENSE` (PolyForm Strict until decided) |
| `lab/docs/Phase*-Implementation-Report.md` and other phase reports | development reports (Russian) |
| `docs/help/` | built-in help and its images (rendered by Backpack from sample data) |
| `docs/settings/`, `docs/themes/`, `docs/plugins/`, `docs/brand/`, `docs/release/` | schemas, SDK docs, release notes, notices, licensing |
| `registry/` | plugin catalog `index.json` (empty), schema, test examples |
| `tools/` | packaging, verification, plugin packing, icon generation, catalog checks |
| `Website/` (sources) | the website project — maintained separately; its own `.gitignore` and notices |

## Not published (`.gitignore`)

| Path | Why |
|---|---|
| `references/` | the author's private screenshots and browser material |
| `research/` | local research material, not required to build the application |
| `artifacts/` | build output and release archives (they go to GitHub Releases, not into git) |
| `TEMP/` | temporary working files |
| `lab/docs/*Handoff*.md`, `lab/docs/Phase4I-Progress.md`, `lab/docs/Phase1B-Experiment-Log.md` | working journals with local paths |
| `lab/docs/*-images/` | screenshots of the real desktop and taskbar taken during checks |
| `docs/review/` | large review sheets (regenerated by `Backpack.exe --lab --render-sheet`) |
| `/keyoverlay-lab-*.json`, `*.keyoverlay-lab.json` | local diagnostics exports |
| `bin/`, `obj/`, `TestResults/`, `*.binlog`, `*.log` | build output |
| `Website/node_modules/`, `Website/dist/`, `Website/.pnpm-store/` | dependencies and build output of the website |
| `*.bppkg` (except `registry/examples/`) | built plugin packages |
| `lab/SettingsWindow.cs`, `lab/SettingsWindow.Pages.cs` | empty leftovers (3 bytes, BOM only) outside any project |

| `Website/qa/`, `Website/scripts/compare-model.mjs` | QA captures, built fixtures and workstation-specific review tooling |

Website sources support the shared catalog validator and source tests; the site is not deployed by this publication.

## Checked

A search over the files to be published found no tokens, keys or passwords (only test code that creates a password field
in the app's own test window) and no personal paths outside the excluded journals.
