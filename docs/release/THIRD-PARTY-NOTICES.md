| Lucide icons (`lucide-static`) | 1.59.0 | ISC; icons derived from Feather — MIT | Path geometry of 195 icons compiled into `Backpack.Visual.dll` (`Icons/LucideIcons.g.cs`, generated by `tools/gen-lucide.py`); the Backpack mark (window, taskbar, tray and EXE icon, logo in the app) is the Lucide `backpack` icon as used by the Backpack website (lucide-react 0.468.0, same ISC license), in `Brand/LogoArt.cs` | below |

Not included in the package:

- **Keyviz** (GPL-3.0) — used only as a functional and visual reference (research clone in `research/keyviz`, not distributed). No Keyviz code, data tables or images are copied; keycap renderers are Backpack's own WPF code written from the documented formulas.
- **Icons8** screenshots and the Backpack concept images — visual references only. No images were cut from them; the logo, mouse icons and the 3D keycap are Backpack's own geometry.
- **Test-only packages** (xunit, Microsoft.NET.Test.Sdk, JsonSchema.Net) — used to build and test, not shipped.

The Backpack logo and icons are original artwork generated from `lab/src/Backpack.Visual/Brand/LogoArt.cs` (source: `docs/brand/backpack-logo.svg`).
